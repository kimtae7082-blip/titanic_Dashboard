# 타이타닉 모델 설명서

## M01 학습과 평가
train.csv 891명을 학습용 712명과 최종 평가용 179명으로 나눈다. 무작위 기준은 42이고 생존 비율을 유지한다. 학습용 5회 교차검증 정확도로 모델을 선택한다. 최종 평가 점수로 다시 선택하지 않는다.

## M02 모델 입력과 빈칸
입력은 객실 등급, 성별, 나이, 동승 형제·배우자 수, 동승 부모·자녀 수, 운임, 승선 항구이다. 생존 정답, alive, 이름은 입력하지 않는다. 수치 빈칸은 학습 구간 중앙값, 범주 빈칸은 학습 구간 최빈값으로 채운다.

## M03 생존율 비교와 예측의 차이
나이 집단 비교는 나이 미상 177명을 제외한 714명이다. 18세 미만과 18세 이상을 비교한다. 예측은 학습 패턴으로 추정한 값이며 역사 속 개인의 실제 운명이 아니다. 원인이나 전체 탑승자 대표성을 입증하지 않는다.

## M04 군집과 비슷한 기록
군집은 생존 정답을 제외한 특징으로 만든다. 군집 번호는 임의적이며 우열이 없다. 사후 생존율은 군집을 만든 뒤 관찰한 값이다. 비슷한 기록의 거리는 수치 표준화와 범주 인코딩 후 계산한 거리이다.
